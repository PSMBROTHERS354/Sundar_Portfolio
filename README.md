# ⚙️ How to Run Locally

No backend or installation is required.

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/SPortfolio.git
```

### 2. Open the project

```bash
cd SPortfolio
```

### 3. Run the website

Open `index.html` directly in your browser.

Alternatively, use **VS Code Live Server**.

---

# 🌐 Run Using VS Code Live Server

1. Open the `SPortfolio` folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

# 🚀 Deployment with GitHub Pages

This is a static HTML/CSS/JavaScript website and can be deployed using GitHub Pages.

### Git commands

```bash
git init
```

```bash
git add .
```

```bash
git commit -m "Initial portfolio"
```

```bash
git branch -M main
```

```bash
git remote add origin https://github.com/YOUR-USERNAME/SPortfolio.git
```

```bash
git push -u origin main
```

Then enable **GitHub Pages** in the repository settings.
